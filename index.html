Practice Online Assessment

A self-contained simulation of the pipeline candidates report for Capital One's Technology Development Program: an untimed Virtual Job Tryout-style situational judgment round, then a timed CodeSignal-style coding round. Pass both, and there's a Power Day loop after — this tool includes prep for that too.

Round 1 · Situational Judgment (untimed)

  • 8 original work scenarios, multiple choice.
  • For each, pick the Most and Least effective response — the common "SJT" format.
  • Tests judgment/work-style (ownership, integrity, customer focus, adaptability), not code.
  • Matches the "Virtual Job Tryout" step Capital One's real OA invite describes.

Round 2 · Coding (70 minutes)

  • 4 questions: Easy, Easy, Medium, Hard — 100 points total.
  • Bank/business-flavored string, simulation, and state-machine problems.
  • Code runs against visible and hidden test cases in a sandboxed Web Worker.
  • No dynamic programming or advanced graph theory — read carefully, model the state.
Each practice run pulls a fresh mix — the 8 situational scenarios, one problem per coding difficulty, and the 10 behavioral questions are all randomly picked and shuffled from a larger pool, so repeated runs don't just repeat the same set.

Made it past the OA? There's a Power Day next.

Preview and practice the onsite loop: 1 behavioral interview + 2 coding interviews + 1 case interview.

How this was built

Format and difficulty pattern based on candidate reports aggregated from Reddit / Blind (teamblind.com) threads and interview-prep write-ups describing Capital One's CodeSignal OA, Virtual Job Tryout, and Power Day onsite loop. See README.md in this repo for sources and caveats — treat this as directional practice, not a guarantee of the real assessment's exact content.
